# Security policy

This repository contains documentation only.

Do not open an issue containing a complete Home Assistant webhook URL, access
token, OAuth credential, private address, public hostname tied to a private
home, entity IDs for security devices, dashboard screenshot, or camera frame.
Replace installation-specific values with placeholders before sharing logs or
configuration.

Report vulnerabilities in HA-MCP, Home Assistant, or ChatGPT to their respective
maintainers through the security channels published by those projects. This
repository does not maintain those products.
